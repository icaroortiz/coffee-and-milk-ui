# Changelog

## 0.1.0 — 2026-11-14

First community edition of Café com Leite UI.

### Added

- Focused AI skill for Soft UI dashboards and internal tools, with brand adaptation and progressive reference loading.
- Design guidance for semantic tokens, restrained elevation, dense content, mobile layouts, keyboard focus and reduced motion.
- shadcn/ui and Tailwind recipes covering existing components, token formats and portaled themes.
- Original scoped CSS preset with light and dark surfaces.
- Interactive studio and operations gallery, plus a React/shadcn example with form validation and a themed dialog.
- English and Brazilian Portuguese READMEs, explicit AI integration instructions and contributor guidance.
- Repository checks, automated builds and a GitHub Pages demo workflow.
- MIT license and preserved third-party notices.

Executed checks and their limits are recorded in [docs/VALIDATION.md](docs/VALIDATION.md). Demo data and submission states are local simulations, not backend functionality.
